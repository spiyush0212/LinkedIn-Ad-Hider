# LinkedIn Ad Hider

A lightweight Chrome extension that automatically hides promoted and sponsored posts from your LinkedIn feed.

## ✨ Features

- Automatically detects and hides promoted/sponsored posts
- Works with dynamically loaded posts as you scroll
- One-click toggle to enable or disable hiding
- Tracks promoted posts hidden during the current session
- Tracks total promoted posts hidden
- Runs entirely in the browser

## 🔒 Privacy

Privacy is a core part of this project.

**LinkedIn Ad Hider does not:**

- Collect user data
- Track browsing activity
- Retrieve or transmit LinkedIn data
- Store any user data on a server
- Require users to create an account
- Require LinkedIn account access or third-party authorization

Extension settings and counters are stored locally in the user's browser.

There is **no backend server** involved.

## 💰 Free & Open Source

LinkedIn Ad Hider is completely free to use.

- No advertisements
- No subscriptions
- No paid features

The project is open source and will be regularly maintained as LinkedIn changes its website and DOM structure.

## 🤔 Why?

There are other browser extensions that attempt to hide promoted content on LinkedIn. However, LinkedIn frequently changes its DOM structure and page implementation, which can cause existing extensions to stop working.

LinkedIn Ad Hider was built to work with the current LinkedIn feed and will be updated as LinkedIn evolves.
